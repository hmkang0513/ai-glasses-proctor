## 고칠 것 (우선순위)
1. **[높음] 휴대폰 안내에 PC 키 이름이 남음**: 적발 버튼을 먼저 누르면 "적발할 학생을 먼저 **관찰(E)**하세요" (`m_03`). 버튼이 7개(관찰·적발·표시·열화상·묻기·CCTV·명부)로 늘었는데 **"표시"·"묻기"는 설명을 본 적이 없음**
2. **[높음] 적발 후 관찰 패널이 안 닫힘** (위 손맛 항목)
3. **[중간] 0명 적발에 칭찬 한마디** (위 4회차)
4. **[중간] 소리 자막이 두 개 겹쳐 뜸**: "◀ 기침"이 거의 같은 위치에 두 번 겹침 (`p1_b6`, `m_03`)
5. **[중간] 4회차 명부의 재응시생 이야기 시간 흐름이 어색**: "6번: **1번째 감독 때** 적발, 응시 자격 정지가 끝나 재응시" — 1번째 감독은 같은 날 아침(바로 3판 전) 느낌이라 "정지가 끝났다"가 맞지 않음. "작년 감독 때"처럼 바꾸거나 회차 간격이 충분할 때만 등장
6. **[중간] 6회차부터 갑자기 어려워짐**: "!"가 없고 조명도 어두움(맑음 고정은 1~5회차) → 뒤에서 단서가 거의 안 보이고 첫 힌트는 106초. 난이도를 올리자는 게 아니라 **계단을 완만하게**: 6~8회차는 "!"를 더 작게/짧게라도 남기거나, 첫 힌트를 60초 안으로
7. **[낮음] "어깨 너머 관찰" 문구**: 뒤에서 관찰하면 제목이 "16번 어깨 너머 관찰 중"으로 바뀌고 뒷머리가 보임. 좋은 아이디어인데 "**집** 주먹 사이로…"는 "**쥔** 주먹"의 오타로 보임 (`p3_c1_obs16`)
8. **[낮음] 뒤에서 관찰하면 AI 안경 단서가 없음**: 10번(AI 안경)을 뒤에서 관찰하니 "눈에 띈 것" 줄이 안 나옴 (`p3_d1_obs10`). "안경다리 끝이 두툼하다"처럼 뒤에서 보이는 문구가 있으면 좋음
9. (3차에서 남은 것, 이번에도 확인) 2회차 입실 설명 명부가 입실 뒤에 나옴 (`p2_00_memo`)

## 아이디어
1. **"!" 대신 소리로 넘겨주기(6회차~)**: "!"를 끄는 대신 부정행위 시작 때 방향 자막(예: "◀ 부스럭", "▶ 딸깍")만 남김. 화면 표시가 사라져도 "어느 쪽"은 알 수 있어 계단이 완만함
2. **한마디 문장 묶음 늘리기 + 같은 문장 연속 금지**: 첫 적발 빠름 / 오인 0 / 뒤쪽 순찰 / 열화상 활용 / 재응시생 적발 등 상황별 3~4개 중 무작위, 직전 회차와 같은 문장은 피하기
3. **휴대폰 "표시"·"묻기" 첫 사용 안내**: 버튼을 처음 누를 때 한 줄 설명 토스트("표시: CCTV에서 고른 학생을 머리 위 점으로 기억합니다" 등)
4. **적발 직후 압수품 클로즈업 1초**: 지금은 작게 뜨는 압수품을 관찰 패널 자리에 크게 1초 보여 주고 닫으면 손맛 + 패널 닫힘 문제를 같이 해결
