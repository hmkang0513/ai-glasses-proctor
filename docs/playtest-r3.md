# 플레이 테스트 3라운드 (2026-11-19, QA 세션)

- 대상: `localhost:5181` 미리보기(커밋 e51dadc "1~5회차 연습 구간" 반영본)
- 방식:
  - **PC**: 1440×810. 저장을 지우고 시작 화면부터 "다음 감독"으로 1→6회차를 이어서 함. 키보드·클릭만 사용
  - **휴대폰**: 844×390 터치. 1회차를 끝까지, 2회차는 입실 검사 화면까지
- 방침: 사용자가 실제로 하는 느낌이 기준이고, 난이도를 올리자는 제안은 하지 않음
- 예외(1·2라운드와 같음): 통로에서 길을 찾을 때만 현재 위치를 읽어 몸을 돌릴 양을 계산함. 누가 부정행위자인지는 결과 화면 전까지 읽지 않음
- 한계: 명령 한 번에 10~30초가 걸려 **실제 걸린 시간은 사람보다 훨씬 김**. 아래 "걸린 시간"은 화면 시계(게임 시각) 기준이고, 시계 확인 12초와 입실 검사 100초는 대부분 지연 중에 지나감
- 스크린샷: `docs/playtest-r3/` (PC `pc1_*`~`pc6_*`, 휴대폰 `mob_*`)

**정리**: 1~6회차 모두 통과해서 "어렵다"는 느낌은 없었음. 다만 **AI 안경 말고는 화면에서 직접 본 단서로 잡은 적이 거의 없음**. 손바닥·훔쳐보기는 가까이에서 10초 가까이 지켜봐도 알아채지 못했고, 매번 부감독 힌트가 뜰 때까지 기다렸다가 그 학생에게 가서 F를 누름. 그래서 초반 회차는 "힌트 기다리기 → 걸어가기 → F" 반복이 되어 지루해질 수 있음

## 고칠 것 (우선순위)

### 1. [높음] 결과 화면: 수첩 줄이 처분 문구와 겹침 (모든 회차, PC·휴대폰)
- 범례가 두 줄(… · 흰 점 못 본 행동 · 초록 점 가까이서 본 행동)로 늘면서 아래 문장이 밀림. "수첩 · AI 안경 (1세대)"가 "행위는 다음 해 응시 자격 정지" 위에 겹쳐 그려짐 (`pc1_07_result.png`, `pc2_30_result.png`, `pc6_30_result.png`, `mob_06_result.png`)
- 범례 첫 줄도 자리 배치도의 마지막 줄과 거의 붙음

### 2. [높음] 첫 부감독 힌트가 너무 늦음
- 2·3회차는 시험 시작 약 90초 뒤(교시 절반), 4회차는 48초, 5회차는 60초, 6회차는 106초에 처음 뜸
- 처음 하는 사람은 그때까지 무엇을 봐야 할지 몰라 교실을 맴돎. 4회차 두 번째 힌트는 148초(교시 끝 30초 전)에 떠서 1교시 안에 갈 수 없었음
- 1~3회차는 20~30초쯤 첫 힌트를 주는 것을 제안

### 3. [높음] 손바닥·훔쳐보기 동작을 화면에서 알아보기 어려움
- 2회차 17번, 3회차 16번(손바닥), 4회차 13·6번, 5회차 11번(훔쳐보기) 모두 가까이 또는 뒤에서 4~10초 지켜봤지만 동작을 못 봄. 관찰 패널도 손 모양이 거의 같음 (`pc2_19_obs17.png`, `pc2_21`~`pc2_23.png`, `pc4_20`~`pc4_23.png`)
- 동작 간격이 길어서인지, 감독관이 보고 있으면 덜 하는지 플레이어는 알 수 없음. 힌트 대상은 **힌트 직후 몇 초 안에 한 번 동작을 보여 주면** "아, 저거구나"를 배울 수 있음

### 4. [중간] "화면 클릭 → 마우스 고정 · Q 명부 보기" 안내 상자가 교실 한가운데를 가림
- 시험 시작 후 6초 동안 화면 중앙(뒤쪽 두 줄 학생 높이)에 떠 있음 (`pc1_02_start.png`, `pc2_11.png`, `pc4_15.png`). 화면 아래쪽이나 위쪽으로 옮기기 제안

### 5. [중간] 2회차 명부(입실 검사 설명)가 입실 검사가 끝난 **뒤에** 나옴
- "오늘부터 입실 검사도 맡습니다. 안경은 벗겨서 바구니에…"가 시험 시작 때 뜸 (`pc2_10_exam.png`). 입실 검사 도움말과 내용이 겹치고 순서도 거꾸로임. 시험 쪽 명부에서는 빼거나 "방금 한 입실 검사는…"으로 바꾸기

### 6. [중간] 휴대폰 입실 검사 안내가 PC 문구
- 도움말에 "물건을 **클릭**하면", "**2 HOLD**", "**1 PASS**", "**클릭**하면 시작합니다" (`mob_10_gatehelp.png`). 버튼도 "1 · PASS" 숫자 표시. 시험 중 문구는 "관찰 버튼", "가까이 가면 적발"로 잘 바뀌어 있어서 입실 검사만 남음

### 7. [낮음] 4회차 이상 2교시 조명이 매우 노랗거나(햇빛) 어두움(흐림)
- 4회차 2교시 화면 전체가 노랗게 바래 학생 구분이 어려움 (`pc4_31`~`pc4_34.png`), 5회차는 반대로 어두움 (`pc5_20.png`). 초반 회차는 날씨를 "맑음"으로 고정하는 것을 제안

### 8. [낮음] 조준 라벨 위치가 관찰 전후로 바뀜
- 관찰 전에는 학생 아래 "14번 [E] 관찰", 관찰 후에는 화면 위쪽 가운데 "14번 [F] 적발 [E] 닫기" (`pc2_12_to14.png` → `pc2_13_obs14.png`). 같은 자리에 있으면 덜 헷갈림

## 휴대폰 (844×390)
- ✅ 버튼이 화면 밖 오른쪽 띠(#touchbar)로 옮겨져 **학생을 가리지 않음**. 1회차 5번이 바로 보임 (`mob_03_look.png`)
- ✅ 시험 중 문구가 "3번 관찰 버튼", "5번 가까이 가면 적발", "관찰 중 · 열화상 3회"로 바뀜 (`mob_04_aim.png`, `mob_05_obs.png`)
- ✅ 1회차 S, 조작에 막힘 없음. 시선 드래그 60px에 약 0.32라디안으로 적당함
- 명부 글씨가 작음(본문 약 9px). 휴대폰에서는 메모 글씨를 한 단계 키우기 제안 (`mob_01_memo.png`)
- 왼쪽 검은 띠(약 75px)는 비어 있음. 걷기 조이스틱 표시 자리로 쓰면 좋을 듯
- 입실 검사 화면에서는 touchbar가 비어 있음(정상). 입실 버튼(PASS/HOLD/CHECK)을 touchbar에 크게 두면 누르기 쉬움

## 재밌던 순간 / 지루한 순간
- 재밌음:
  - 1회차에서 고개를 돌리자 **빨간 LED가 멀리서 깜빡이는** 순간
  - 입실 검사에서 본 카메라 경첩(2회차 14번, 3회차 10번, 5회차 18번)을 **시험 중에 다시 찾아가 잡는** 흐름
  - 6회차 명부의 "2번 자리: 2번째 감독 때 적발된 학생, 재응시"라는 이어지는 이야기
- 지루함:
  - 힌트가 뜨기 전 60~100초 동안 할 일이 없음
  - 4회차부터 2교시까지 3분 더 해야 하는데, 1교시와 똑같이 힌트를 기다리게 됨
  - 입실 검사 20명 중 단서가 있는 학생은 1명 정도라 나머지 19번은 PASS만 누름

## 아이디어 (5개)
1. **"수상한 순간" 짧은 강조**: 1~5회차에서 부정행위 동작이 시작되면 그 학생 머리 위에 작은 "!"를 1초 띄움(가까이 있을 때만). 힌트를 기다리지 않고 **직접 발견하는 재미**를 줌. 6회차부터는 끄기
2. **입실 검사 빠른 넘기기**: 금속 막대가 0~2칸이고 의심 물건이 없는 학생은 Space 한 번으로 "이상 없음, 다음"을 연속 처리. 의심 학생에서만 멈추게 해서 20명 → 실제로 보는 건 3~4명
3. **힌트를 단계로**: "부감독이 창가 쪽을 봅니다"(구역) → 20초 뒤 "창가 둘째 줄"(줄) → 다시 20초 뒤 "6번"(자리). 바로 답을 주는 대신 좁혀 가는 재미. 1~3회차는 지금처럼 바로 자리 번호
4. **감독관 수첩 '수법 카드'에 짧은 움짤**: 처음 잡은 수법은 결과 화면에서 그 학생의 동작 2~3프레임을 반복해 보여 줌. "손바닥 커닝은 이렇게 생겼구나"를 배우고 다음 회차에서 직접 찾을 수 있음
5. **재응시생 이야기 확장**: 6회차처럼 예전에 잡은 학생이 다시 나오면, 그 학생은 **예전 수법과 다른 수법**을 쓰거나 아예 깨끗하게 시험을 봄. 결과 화면에 "2번 학생은 이번엔 정직하게 봤습니다" 한 줄을 넣으면 이야기가 생김
