# AI 안경 감독관 게임 — 계획

## Context
2026년 AI 스마트 안경 시험 부정행위 논란(토익·자격시험·대학 논술에서 적발, 국내 첫 형사 기소, 수능 판별 전담 요원 배치)을 주제로 웹 게임을 만든다.
플레이어는 감독관이 되어 학생 20명 가운데 부정행위자를 잡는다. 단계가 올라갈수록 실제 수법에 가까워지고 알아채기 어려워진다.

**사용자 결정**
- 플랫폼: 웹 브라우저, **2D 픽셀**
- 모드: **선생님 모드**(교실을 걸어 다니며 순찰)를 먼저 만들고, **CCTV 모드**를 선택할 수 있게 한다. 입실 검사 단계(Papers, Please 방식)는 나중에 추가
- 학생: 20명
- 참고 저장소: LutLight2D(조명), pixelfx, pixelgraphics, pixel-art-studio

## 기술 스택
- **Vite + TypeScript + Canvas 2D**, 게임 프레임워크는 쓰지 않는다
- 내부 해상도 **480×270** 프레임 버퍼 → 화면에서 정수배로 확대하고 `image-rendering: pixelated` 적용 (pixelfx 방식과 같음). LPC 캐릭터가 64×64 프레임이라 320×180은 너무 좁아서 키웠다. 교실은 화면보다 조금 크게 만들어 카메라가 교사를 따라간다
- 렌더 순서: 배경·책상 → 학생 → pixelfx(back/front) → **LUT 조명 패스** → HUD
- 프로젝트 위치: `D:\dev\ai-glasses-proctor`

## 핵심 게임 규칙
- 시험 1회에 제한 시간(예: 3분)이 있고, 그 안에 부정행위자 2~5명을 적발해야 한다
- **선생님 모드 (1인칭)**: 둠 방식 의사 3D. 방은 원근 다각형으로, 학생은 픽셀 스프라이트를 거리에 맞춰 크기를 바꿔 그린다(빌보드). WASD로 걷고 마우스로 고개를 돌린다. 멀리 있는 학생은 작아서 단서가 잘 안 보인다. 등 뒤의 학생은 대담해지고, 감독관이 다가오면 부정행위자가 행동을 멈춘다. 오른쪽 아래에 감독 명부를 든 손
- **CCTV 모드**는 위에서 내려다보는 천장 카메라 시점(탑다운)
- **[E] 관찰**: 근처 학생의 얼굴·손을 64×64 클로즈업 패널로 본다. LED, 이어피스, 입술 움직임이 여기서 보인다
- **[F] 적발**: 잘못 적발하면 민원 게이지가 오르고, 가득 차면 게임 오버. 놓친 부정행위자는 감점
- **CCTV 모드**: 카메라 4대를 1~4 키로 전환한다(전환할 때 pixelfx glitch). 교실 전체가 보이고 학생에게 들키지 않지만, 화질이 낮아(초록·회색 LUT, 노이즈, 타임스탬프) 작은 단서는 안 보인다. 행동 패턴만으로 판단해야 한다
- **무고한 학생도 비슷한 행동을 한다**(귀 긁기, 일반 안경 고쳐 쓰기, 시계 보기, 기지개). 난이도는 행동 하나가 아니라 단서를 어떻게 조합하느냐에서 나온다
- 결과 화면: 적발·놓침·오인 수 + 실제 사례 한 줄과 기사 링크

## 조명(LUT)과 이벤트
- 단계와 조명은 묶지 않는다. 날씨(맑음·흐림)는 무작위
- **정전은 무작위 이벤트**: 예고 없이 깜빡이다 꺼짐 → 뒷벽 스피커 음파 + "EVENT!" + [방송실] "갑작스러운 정전입니다… 늦어진 시간만큼 시험 시간을 연장합니다" → 타이머 연장. 어두우면 LED가 눈에 띄지만 얼굴·손은 잘 안 보임 (근거: 2023학년도 수능 제주 정전, 5분 추가)
- 수법 목록 30종(실제 사례 근거 포함)은 목업 artifact의 "개발용 전체 목록"을 `src/data/cheats.ts`로 옮긴다
- 다른 이벤트 후보: 듣기평가 방송(감독관 이동 시 민원), 화장실 요청(다녀온 뒤 기기 반입 가능). 세부 규정은 미검증 → 평가원 감독관 지침으로 확인
- CCTV 모드는 같은 LUT 시스템에 다른 램프(초록 모노톤)를 넣어 구현한다

## 한 판의 흐름 (2026-11-18 결정)
- 한 판 = 시험 하루(8~10분): **입실 검사(1회, 약 2분) → 1교시(3분) → 쉬는 시간(30초) → 2교시(3분) → 결과**
- **모든 레벨이 수능**. 레벨 = 감독 경력(N번째 감독), 시험실은 매번 가상 학교 + 현실적인 시험실 번호(예: 한빛고 제7시험실). 레벨 수 제한 없음
- **저장**: 레벨·감독관 수첩·설정을 localStorage에 저장(try/catch, 실패해도 게임은 동작). 같은 브라우저·기기에서만 이어짐. 기기 간 이어하기는 나중에 "이어하기 코드"로 검토
- 난이도 곡선: AI 안경 세대(1세대 LV1~ / 2세대 LV10~ / 3세대 일반형 LV25~ / 4세대 저발열 LV50~), 부정행위자 1→6명, 미끼 2→7명+, 수법 30종은 LV1~49 사이에 조용히 해금, 이후엔 조합·이벤트 빈도·입실 시간으로 조절
- 교시: 1교시 국어, 2교시 수학 (실제 수능 시각 압축)
- 열화상: 작동 직후(촬영·음성 질문 후 약 10초)만 뜨거움, 교시당 2~3회 제한. 실제 근거는 대만 사례의 "만져서 발열 확인"이고 열화상 카메라는 게임 도구
- **감독관 수첩**: "도감" 대신 손에 든 감독 명부 뒷장. 처음 밝혀진 수법이 손글씨 메모로 남음. 진행도 숫자는 표시하지 않음, 시험 중 Q로 넘겨 봄 (평가원 "수능 시행 관리 사례집"에서 착안)
- 화면 시계는 실제 시험 시각으로 압축해 흐름(수능: 입실 08:10, 1교시 08:40~10:00 = 게임 3분). 나머지 교시 시각은 평가원 시행세부계획으로 확인 후 반영
- 결과 화면 = 감독 결과 보고서: 자리 배치도(적발 주황·놓침 빨강·오인 빗금), 적발·놓침·오인·남은 시간·보너스, 등급 도장, 놓친 학생 수법 공개, 오인 사유, 도감 기록, 처분(해당 시험 무효)
- 시작 화면: 시험장 학교 정문, 시험 종류 선택(잠금), 1인칭/CCTV 선택, 도감 진행도

## 적발과 진행 규칙
- 적발 시 조용히 처리: 퇴실 안내 → 학생이 뒷문으로 나감 → 빈자리로 남기고 계속 진행. 폭죽 같은 큰 효과 없음
- 전체 부정행위자 수는 숨김(CAUGHT n/?). 마지막 한 명을 잡으면 즉시 종료, 못 찾으면 시간 끝까지 진행 후 결과 화면에서 놓친 학생과 수법 공개
- 입실 검사: 기기를 스스로 내면(HOLD) 보관하고 응시, 숨기다 걸리면 퇴실 → 시험 시작 때 빈자리
- 입실에서 다 잡아도 시험은 진행(플레이어는 모름). 오인 적발 없으면 "완벽한 입실 검사" 보너스
- 쉬는 시간·화장실 반입 학생은 **확률**로 등장(예: 1단계 30%, 4단계 80%), 필수 아님

## 안경 디자인과 수법 계열 (2026-11-18)
- 일반 안경 8종: 은테, 건메탈 회색테, 금색 동그란 테, 검은 뿔테(1세대 AI 안경과 헷갈리는 미끼), 갈색 뿔테, 남색 뿔테, 회색 반무테, 투명테. 모양(metal·round·half·horn) × 색
- AI 안경 = 일반 디자인 + 세대별 AI 부품. 1세대 두꺼운 안경다리·카메라·LED, 2세대 작은 경첩·가린 LED·작은 카메라 구멍, 3세대 부품 안 보임
- 모든 수법을 계열로 묶어 초급→중급→고급 + 미끼 + 잡는 방법을 둔다: AI 안경, 스마트워치, 이어폰, 휴대폰, 쪽지·메모, 숨긴 카메라, 공모·신호, 사람·조직 (상세는 목업 "수법 계열별 진화" 표)

## 다른 수법과 수상한 행동
- 안경 착용 약 55%(시험실마다 20명 중 9~13명 무작위, 목업은 11명). 근거: 교육부 2025 학생건강검사 시력 이상 58.25%(초·중·고 전체, 교정 중 또는 맨눈 0.7 이하), 광주 고3 한 학교 조사 안경 74%(2007, 표본 작음), 콘택트렌즈 착용자를 감안해 낮춤. 고3 전국 안경 착용률 공식 통계는 못 찾음. 안경 안 쓴 학생은 AI 안경 용의자에서 빠지지만 다른 수법(커닝페이퍼·스마트워치·이어폰 등)은 쓸 수 있음. 콘택트렌즈 같은 변수는 넣지 않음
- AI 안경이 큰 줄기, 다른 수법(커닝페이퍼, 옆자리, 스마트워치, 책상 밑 휴대폰, 이어피스, 물병 라벨, 수신호 공모 등)이 단계마다 **안내 없이** 추가. 직접 만난 수법만 도감에 기록
- 수상한 행동은 부정행위자와 무고한 학생이 모두 함: 안경다리 만지기, 코받침 밀기, 안경 벗었다 쓰기(렌즈 닦기), 두리번, 손 책상 밑, 오래 멈춤, 입술 움직임, 손목 보기. 판단은 행동의 맥락(무엇과 이어지는지)으로

## 단계별 부정행위 (조사 기반, `src/data/cheats.ts`에 출처 URL 주석)
모든 단계가 AI 안경 이야기다. 단계가 오를수록 안경이 일반 안경을 닮아 가고, 단서가 겉모습에서 행동으로 옮겨 간다 (2026-11-17 사용자 결정).
| 단계 | 안경 | 단서 |
|---|---|---|
| 1 겉모습 | 두꺼운 테, 카메라, LED | 가까이 가면 LED가 보임. 조작법을 익히는 단계 |
| 2 겉모습+행동 | 얇은 검은 테, LED 테이프로 가림 | 안경다리 만지기, 시험지를 이상한 거리에서 오래 응시, 열 감지(횟수 제한) |
| 3 행동 | 일반 안경과 똑같음 | 멈춰서 노려봄 → 입술 움직임 → 답을 몰아서 씀 (게임 설정). 고민하느라 멈추는 무고한 학생이 미끼 |
| 4 행동+미끼 | 일반 안경과 똑같음, 2명 이상 | 미끼 학생 증가, 이벤트 빈도 증가 |

## 입실 검사 (시험 전 단계)
- 학생이 한 명씩 들어온다. 안경을 벗어 바구니에 올리고(중국 가오카오 방식), 수험표·소지품을 확인한 뒤 PASS / HOLD(보관) / CHECK(추가 확인)를 고른다
- 도구: 확대경(경첩 6배, 일반 안경처럼 생긴 AI 안경의 카메라 구멍), 금속 탐지(일반 금속테·아날로그 시계에도 울림 → 미끼)
- 입실 마감 08:10 타이머. 꼼꼼히 볼수록 줄이 밀린다

## 그림 스타일 (2026-11-18 결정: A)
- 목업처럼 코드로 그린 픽셀 학생을 기본으로 다듬는다. LPC 캐릭터는 쓰지 않음(비교 후 탈락: 부정행위 동작을 전부 새로 그려야 하고 CC-BY-SA 조건이 붙음)
- 다듬을 때 pixel-art-studio를 보조 도구로 사용 가능

## 필요한 에셋 (아래 LPC 관련 항목은 A 결정으로 보류)
- **LPC 생성기**: 교사 4방향 걷기, 학생 기본 몸 20종(머리·옷 조합). 크레딧 파일 함께 저장
- **pixel-art-studio (LPC 스타일에 맞춤)**: 학생 앉은 자세 동작 — 필기, 고개 옆으로, 아래 보기, 안경다리 만지기, 시험지 들기, 손목 보기, 귀 만지기, 입술 움직이기, 기지개, 긁기. 동작은 머리·팔 레이어로 그려 20명의 몸에 공통 적용
- 학생 얼굴 클로즈업(64×64): 일반 안경 / AI 안경(LED 켜짐·꺼짐) / 이어피스
- 교실 타일셋(책상·칠판·창문·시계·문), HUD 프레임. LPC 타일셋이 OpenGameArt에 있으면 우선 사용
- 앉은 학생 동작이 손으로 그리기 너무 어려우면 그때 PerfectPixel을 검토

## 마일스톤
1. 프로젝트 생성 + 목업 렌더링 코드 이식(1인칭 교실·학생 20명·LUT 조명) + WASD/마우스 이동
2. 행동 시스템(무고 행동 + 1·2단계 수법), 관찰·적발·점수·결과 화면
3. LUT 조명 + 3·4단계 AI 안경 수법 + 단계 진행 + pixelfx 이펙트
4. CCTV 모드
5. 입실 검사 단계 (검사 결과가 시험 단계의 부정행위자 명단으로 이어짐)

## 검증
- `npm run dev`로 실행해 직접 플레이: 이동, 시야 범위, 관찰 패널, 적발 판정, 오인 시 민원 게이지, 시간이 끝나면 결과 화면
- webapp-testing(Playwright)으로 모드별 스크린샷을 찍고 콘솔 에러를 확인
- 단계마다 무고한 학생과 부정행위자를 구분할 수는 있되 쉽지 않은지 플레이 테스트로 조정
