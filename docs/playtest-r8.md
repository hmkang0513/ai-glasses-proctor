## 처음 하는 사람 느낌 (1→4회차)

- **1회차 메모 두 줄** (`a1_memo`): "WASD로 걷고 마우스로 고개를 돌립니다 / 수상한 학생을 화면 가운데 두고 E로 관찰, 확실하면 F로 적발" — 짧고 충분. 남은 인원·부감독 힌트·"!" 설명은 2회차 명부로 옮겨졌는데, 1회차에서 "!"가 처음 떴을 때 13초쯤 **"머리 위 '!' = 방금 수상한 행동…"** 토스트가 따로 나와서 괜찮음
- **증거물 폴라로이드 카드** (`a1_after`, `a1_closed`, `a2_res`): 결과 화면 위에 사진 카드가 비스듬히 뜨고, 누르면 뒷면(실제 사례·설명), 한 번 더 누르면 닫힘. "처음 잡았다"는 기념 느낌이 좋음
  - 아래 안내가 **"처음 밝혀낸 수법 · 누르면 뒤면"** → "뒷면"의 오타로 보임
  - 안내 줄이 화면 맨 아래 "다음 감독" 버튼 바로 밑에 붙어 있어 버튼 문구처럼 보임
  - **손바닥 커닝 카드도 얼굴 사진**이라 수법이 안 보임 (`a2_res`). 손바닥 클로즈업이면 "증거물" 느낌이 더 날 듯
  - 카드가 뜬 동안 "다음 감독"을 누르면 카드만 닫히고 넘어가지 않음 → 두 번 눌러야 함(헷갈렸음)
- **교무실 한 컷** (`a2_staff1`, `a3_staff`, `a4_staff`): 판 결과에 맞는 동료 한마디 ("첫 감독 어땠어요? 저도 처음엔 다리가 후들거렸어요" / "벌써 찾으셨어요? 눈이 매섭다고 소문나겠는데요" / "다 잡는 사람은 없어요. 놓친 건 결과 보고서에서 한 번 보고 가요"). 짧고 따뜻함 ✅. 책상 위 물건 변화는 4판 안에서는 못 알아봄
- **입실 6명**(2회차) (`a2_g1`~`a2_g6`): 금방 끝나서 부담이 없음 ✅. "나머지 14명은 부감독이 검사했습니다" 라벨이 학생 얼굴 아래(옷깃)를 살짝 덮음
- **2회차 명부 순서**: 이제 입실 검사가 끝난 뒤 "입실 검사 수고했습니다. 검사에서 놓친 기기는 시험 중에 꼭 다시 쓰게 됩니다" → 자연스러움 ✅ (`a2_memo`)
- **입실 10명**(4회차): "1/10" 확인, 새 도움말 OK (`a4_g0`)

## 반장 제보

- 14회차: 부감독 힌트 62초, 반장 손 69초 → **7초 간격**으로 연달아 뜸. 10초 겹침 금지가 토스트 시작 기준이면 맞지 않음 (확인 부탁)
- 반장 손 든 모습과 머리 위 네모 표시가 교실 뒤에서도 잘 보임 (`b14_t20`)
- 15회차: 반장 앞에 서서 기다림 → 손을 내린 뒤에도 라벨 **"1번 [E] 반장 제보 듣기"** 유지 → E → "반장(작은 목소리): 창가 쪽 앞쪽에서 누가 손을 자꾸 내려다봐요." ✅ (`b15_r0`~`b15_r3`)
  - 같은 문장이 화면 위 토스트와 관찰창 위 줄에 **두 번** 나옴. 한 곳이면 충분
- 14회차에서 "아주 늦게(교시 끝 무렵)" 가는 경우는 제가 시간 안에 도착하지 못해 **미확인**

## 휴대폰 1회차
- 새로 생긴 **시험실 문 장면**("제7시험실", "누르면 건너뛰기") (`mm_memo`) — 분위기 좋음. 다만 메모를 닫으려던 탭이 이 장면을 넘기는 데 쓰여, 바로 다음 화면이 기대와 달랐음
- 자동 조준 덕분에 항상 누군가 잡히는데, 제가 화면을 안 보고 연달아 누르니 가장 가까운 8번(무고)이 세 번 탭으로 적발 처리됨(1회차라 경고) (`mm_F`). 라벨에 번호가 있으니 버그는 아님. 휴대폰에서는 마지막 확인 탭 직전에 **관찰창을 1초 이상 보여 준 뒤에만 확인을 받으면** 실수 탭이 줄 듯
