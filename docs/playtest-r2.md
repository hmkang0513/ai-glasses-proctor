# 플레이 테스트 2라운드 (2026-11-18, QA 세션)

- 대상: 로컬 빌드(`npm run build` → `vite preview --port 5182`). 배포 주소는 쓰지 않음
- 방식:
  - **휴대폰 흉내**: Playwright msedge, `has_touch=True`, `is_mobile=True`, 가로 915×412(배율 2). CDP 터치 이벤트로 탭·드래그만 보냄
  - **PC**: 1440×810, 키보드와 클릭만 보냄
- 1라운드와 같은 예외: 길을 잃었을 때만 현재 위치와 방향을 읽어 몸을 돌릴 양을 계산함. 학생 정보는 결과 화면 전까지 읽지 않음
- 한계: 명령 한 번에 10~30초가 걸려서 입실 검사는 화면을 기록하며 빠르게 넘겼고, 시계 확인(12초)은 대부분 지나간 뒤에 들어감
- 스크린샷: `docs/playtest-r2/` (휴대폰 `m1_*`·`m12_*`, PC `p16_*`·`p40_*`)

## 가장 큰 문제 3개

1. **휴대폰에서 버튼 묶음이 학생을 가림**: 관찰·적발·열화상·CCTV·명부 버튼 5개가 화면 오른쪽 아래 약 1/4을 덮음. 1회차 부정행위자(5번, 오른쪽 앞줄 끝)가 **버튼 바로 뒤에 숨어** 처음 화면에서 보이지 않음 (`m1_02_exam.png`, `m1_03_look.png`, `m1_06_aim5.png`). 화면 오른쪽 끝 학생을 보려면 시선을 돌려 가운데로 데려와야 함
2. **결과 화면 겹침·잘림이 PC·휴대폰 모두 남아 있음**:
   - 놓친 학생 상자가 범례 줄("… · 흰 점 못 본 행동")의 오른쪽 끝을 덮음 (`m12_50_result.png`, `p16_70_result.png`, `p40_40_result.png`)
   - 두 번째 상자는 "(행동 33번"에서 잘림 (`p16_70_result.png`)
   - 놓친 학생이 5명이어도 상자는 1~2개뿐이고 "외 n명"이 없음 (`p40_40_result.png`)
3. **휴대폰인데 PC 조작 안내가 그대로 나옴**:
   - 1회차 수석감독관 메모가 "WASD로 걷고, 마우스로…, 클릭하면 마우스가 고정"
   - 조준 라벨이 "[E] 관찰", "[F] 적발 [E] 닫기"
   - 관찰 패널 제목이 "T 열화상", 하단이 "클릭하거나 Space를…"
   - (`m1_01_memo.png`, `m1_02_exam.png`, `m1_09_obs.png`)

## 휴대폰 1회차 — 나래고 제15시험실 · A (5번 AI 안경 1세대 적발, 민원 0.5)
- **할 일**: 화면 위 "왼쪽을 끌면 걷기 · 오른쪽을 끌면 고개 돌리기" 안내가 바로 보여서 조작은 금방 알았음 (`m1_02_exam.png`). 메모 본문은 PC 안내(위 3번)
- **찾기**: 5번이 버튼 뒤에 숨어 있다가, 고개를 오른쪽으로 돌리자 팔을 관자놀이에 올린 모습과 **빨간 LED**가 보였음 (`m1_03_look.png`, `m1_07_aim5.png`)
- **조작 불편**:
  - 시선 드래그는 40px에 약 0.2라디안. 미세 조정은 괜찮지만, 한 번 손가락을 놓고 다시 끌어야 해서 조준을 3~4번 고쳐야 했음 (`m1_04`~`m1_08`)
  - 조준을 고치는 동안 바로 앞 4번 옆(1.3m 안)에 머물러 **쳐다봄 민원 0.5**가 들어옴 (`m1_07_aim5.png`). 터치는 조준이 느리니 경고나 유예가 더 필요해 보임
  - 관찰 패널(왼쪽 아래)이 조준 라벨 앞부분을 덮어 "5번"이 안 보이고 "번 가까이 가면 [F] 적발"만 보임 (`m1_09_obs.png`)
  - 화면 양옆 검은 띠(캔버스 밖)에서 시작한 드래그는 무시됨. 오른쪽 끝에서 크게 돌리려다 실패. 띠 영역도 시선 드래그로 받아 주면 좋음
- **좋았던 점**: 가까이 가서 적발 버튼을 누르자 바로 끝나는 흐름은 휴대폰에서도 자연스러움 (`m1_13_result.png`)

## 휴대폰 12회차 — 새솔고 제26시험실 · C (19번 적발, 놓침 2번 지우개·6번 손바닥, 민원 0.5)
- **입실 검사**:
  - 지우개를 탭하면 확대경에 **안쪽 글씨**가 보임. 2번 단서가 분명함 (`m12_g02.png`)
  - 19번은 경첩 카메라 + 머리 금속 4칸(주황) (`m12_g19.png`)
  - 금속 깜빡임 노이즈가 사라져 읽기 쉬워짐
  - 버튼은 여전히 "1 · PASS", "2 · HOLD"처럼 숫자 키 표시. 휴대폰에서는 숫자가 의미 없음
- **시험 중 19번**: 시험지를 얼굴까지 듦 → 관찰 → 열화상 → 적발. 1라운드와 같이 만족스러운 흐름 (`m12_21.png`, `m12_24_thermal.png`)
- **소리 자막**: "▼ 진동음 (뒤)", "▶ 기침", "◀ 딸깍"이 화면에 떠서 방향 단서가 됨. 좋음. 다만 "진동음" 자막이 조준 라벨 근처에 떠서 겹칠 때가 있음 (`m12_20_obs19.png`)
- **부감독 힌트** "6번 쪽"은 맞았지만, 6번 옆에서 6초 지켜보는 동안 손바닥 동작은 보지 못함 (`m12_31_obs6.png`~`m12_34.png`)
- **정전**: 내 지연 때문에 시작 연출은 놓치고 복구 안내만 봄. 정전 중에도 관찰 패널의 얼굴은 밝게 그대로 보여서, "어두우면 얼굴·손이 잘 안 보인다"는 기획과 다름 (`m12_33.png`)
- **결과 화면**: 범례 겹침, 놓친 학생 2명 중 1명만 공개 (`m12_50_result.png`)

## PC 16회차 — 누리고 제7시험실 · C (16번 AI 안경 2세대 적발, 2번 스마트워치 시계 확인 때 보관, 놓침 6번 창밖 쪽지·14번 자 메모)
- **입실 검사**: 단서가 분명함
  - 2번: 검은 스마트워치 + 손목 금속 5칸(빨강) (`p16_g02.png`)
  - 16번: 경첩 카메라 + 머리 5칸 (`p16_g16.png`)
  - 19번의 검은 아날로그 시계는 손목 2칸이라 **금속 칸 수로 구분됨**. 1라운드에서 오인했던 문제가 해결됨
- **시험 시작 명부**에 전파 탐지기(R) 설명이 나옴 (`p16_11_pre2F.png`). 다만 시계 확인 시간이 명부를 닫을 때까지 멈춰 있어서 좋았음
- **시계 확인**: 2번에게 가서 관찰 → F → "스마트워치 보관, 시험은 그대로 봅니다". 이번에는 시간 안에 해냄 (`p16_10_pre2.png`)
- **불편**:
  - 시계 확인 때 연 관찰 패널을 닫지 않고 교실 반대편까지 걸어가도 패널이 **흐릿한 채로 계속 떠 있음**("멀어서 흐릿합니다 · 조금 더 다가가세요"). 화면 왼쪽 40%를 계속 가림 (`p16_21.png`)
  - 학생을 **뒤에서 보면 등 모습**으로 바뀐 점은 좋은데(`p16_40.png`), 관찰 패널은 뒤에서 봐도 앞얼굴을 보여 줌 (`p16_53.png`)
- **창밖 쪽지**: 교실 뒤에서 창밖에 서 있는 사람 그림자와 창가 학생의 팔 동작이 보였음. 어느 학생인지 찾다가 엉뚱한 11번으로 감. 결과를 보니 6번이었음. 창밖 사람이 **보이는 시간이 짧아서** 위치를 잡기 전에 사라짐 (`p16_45.png`, `p16_50.png`~`p16_51.png`)
- **"종료 10분 전" 방송**: 분위기가 좋음 (`p16_55.png`)
- **결과 화면**: 범례 겹침과 두 번째 상자 잘림 (`p16_70_result.png`)

## PC 40회차 — 한빛고 제3시험실 · D (5번 적발, 놓침 9번 AI 안경 일반형·10·13·14·17번, 민원 0.5)
- **시작 명부**: "13번 자리: 16번째 감독 때 'AI 안경(2세대)'로 적발된 학생입니다. 응시 자격 정지가 끝나 재응시했습니다" (`p40_10_start.png`). 이야기가 이어져서 재미있음. 실제로 13번은 이번에도 부정행위자였음(놓침)
- **입실 검사**: 5번 머리 4칸(주황), 17번 **몸통 4칸**, 19번 손목 3칸 (`p40_g05.png`, `p40_g17.png`). 몸통 반응은 CHECK를 해야 하는데 이번엔 빠르게 넘김
- **전파 탐지기**: 계기판에 "평소/송신" 눈금과 "바늘이 빨간 영역이면 근처 무선 기기가 송신 중" 설명이 생겨 읽을 수 있음 (`p40_12_R5.png`)
- **새 문제**: 시계 확인 중에도 **R(전파)를 쓸 수 있고 횟수가 줄어듦**(2→1). T는 막혔는데 R은 안 막힘 (`p40_12_R5.png`)
- **듣기평가(3교시)**:
  - 시작 4초 전 "듣기평가 4초 전 · 자리를 잡으세요 (Shift 까치발)" 안내 → 방송 자막 "감독관은 듣기평가 동안 이동을 자제해 주십시오"
  - 걸었더니 즉시 "듣기평가 중 발소리가 시끄럽다는 민원" 0.5 (`p40_31_p3start.png`~`p40_34.png`)
  - 규칙은 분명하고 실제 사례와도 맞음. 다만 4초 예고는 짧고, 방송 자막 상자가 조준 라벨을 덮음 (`p40_33_walk.png`)
  - Shift 까치발은 테스트 도구 문제로 확인하지 못함(미확인)
- **점심시간 화면**(12:10~13:00)이 쉬는 시간과 구분되어 나옴. 좋음 (`p40_30_break2.png`)
- **결과 화면**: 범례 겹침, 놓친 5명 중 1명만 공개 (`p40_40_result.png`)

- 검은 아날로그 시계와 스마트워치 구분: 손목 칸 수로 구분됨 ✅
- 조준 라벨이 옆 학생 얼굴을 덮는 문제: 라벨이 대상 아래로 내려가 해결 ✅. 다만 관찰 패널·방송 자막과 겹치는 새 경우가 있음

## 개선 아이디어
- 휴대폰 버튼을 화면 오른쪽 **검은 띠(캔버스 밖)**로 옮기거나, 반투명·작게 만들고 관찰·적발만 크게
- 휴대폰에서는 모든 안내 문구의 키 이름을 버튼 이름으로 바꾸기(관찰 버튼, 적발 버튼, 화면을 탭하면…)
- 결과 화면: 놓친 학생 상자는 최대 2개 + "외 n명", 상자 아래 한계를 범례 위로
- 관찰 패널은 관찰 거리(4.2m)의 2배쯤 멀어지면 자동으로 닫기
- 시계 확인 중에는 R도 막기
- 듣기평가 예고를 10초 전부터, 방송 자막은 화면 위쪽에
- 창밖 사람이 나타날 때 창문 쪽에서 "▶ 똑똑" 같은 소리 자막을 띄워 방향 단서 주기
