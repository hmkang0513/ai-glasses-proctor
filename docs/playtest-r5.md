## 막힘·어색함 (우선순위)

### 1. [높음] 멀리서 F 자동 다가가기가 **엉뚱한 학생**을 잡기 쉬움
- 10회차: 13번을 보려 했는데 화면 가운데에 앞줄 8번이 걸려 있었음. 관찰창은 8번인데 라벨이 "8번 [F] 다가가서 적발"로만 나와 확인 못 하고 F → 8번까지 걸어가 바로 적발, 민원 1 (`r10_f1_obs13`~`r10_f3`)
- 휴대폰 1회차: 적발 탭 → 관찰창(4번, "멀어서 흐릿합니다") → 다시 탭하니 **흐릿한 채로** 4번에게 걸어가 적발 처리(1~2회차라 경고로 넘어감). 그 뒤 4번 바로 앞에 서 있어서 다음 탭이 또 4번을 잡음 (`m_03_Fobs`~`m_05_F`, `m_06`)
- 제안: 자동 다가가기는 **도착 후 멈추고 관찰창을 선명하게 보여 준 뒤**, F를 한 번 더 눌러야 적발. "확인한 뒤 적발을 한 번 더 누르세요" 안내와도 맞음

### 2. [높음] 결과 화면 한마디가 상황과 어긋남
- 10회차(오인 2명, 민원 2.5): "부정행위자를 찾아냈습니다. 잘했어요. 다음엔 뒤쪽 줄도 한 번 가 봅시다." — 오인을 언급하지 않고, 뒤쪽 줄은 이미 다녀왔음 (`r10_z_result`)
- 12회차: "머리 위 '!'나 H(부감독에게 묻기)를 써 보세요" — 12회차엔 "!"가 없음. "H"는 PC에서 한 번도 설명을 본 적 없음 (`r12_z_result`)

### 3. [높음] 결과 화면 겹침: "★ 작은 목표" 줄이 버튼 밑으로 들어감
- 12회차 D 화면에서 "★ 작은 목표 · 뒤쪽 줄까지 한 바퀴 돌기 달성!"이 "다시 감독하기" 버튼과 겹침 (`r12_z_result`). "D 등급: 다시 맡습니다"와 같은 줄에 있어서 생기는 듯

### 4. [중간] 작은 목표 "뒤쪽 줄까지 한 바퀴"가 **시계 확인 중 걸어간 것만으로 달성**
- 08:40 시험 시작과 동시에 "★ 작은 목표 달성!" (`r12_b1`). 시험 시간에만 세기 제안

### 5. [중간] 놓친 학생 설명마다 "종료령 뒤에도 답안을 썼습니다"가 붙음

### 6. [중간] 오인 사유(부감독 힌트가 틀림)가 결과에 안 보임

## 좋아진 것 ✅
- 6~9회차 첫 힌트가 50~70초로 당겨져 기다림이 줄었음 (6회차 68초, 7회차 2교시 62초)
- 쉬는 시간 **돌아보기 카드**: "15번 · 지우개 포장지가 조금 벌어져 있다", 적발 0명일 때 "다음 교시에도 비슷한 것이 보일 수 있어요" — 짧고 좋음 (`r6_c6`, `r7_d1`)
- **오늘의 작은 목표**(열화상 한 번 써 보기 → 별 도장): 해 볼 일을 줘서 좋음. 7회차 결과에 "★ 작은 목표 달성!" (`r7_z_result`)
- **학생 한 줄 소개**("명부: 일찍 입실함", "물을 자주 마심", "렌즈를 자주 닦음"): 미끼 습관을 미리 알려 줘서 오인을 줄이는 데 도움
- **10회차 열화상 시범**: "부감독 시범: 안경다리를 누릅니다" → "만진 직후 열화상(T) → 안경다리가 뜨겁다!" 순서가 분명함 (`r10_b1`, `r10_b3`). 단, 시범이 명부를 연 상태에서 시작되어 명부 뒤에 가려짐 → 명부를 닫은 뒤 시작하면 더 좋음 (`r10_memo1`)
- 휴대폰: 관찰 안 한 학생에게 적발을 누르면 관찰창을 먼저 열어 줌, 1회차 메모에 "!" 설명 추가 (`m_01_memo`, `m_03_Fobs`)

## 아이디어
1. **자동 다가가기 = 확인 단계**: 멀리서 F → 걸어가서 멈추고 관찰창 선명하게 + "F 한 번 더 = 적발" (위 1번 해결)
2. **결과 한마디 우선순위**: 오인 > 놓침 > 칭찬 순서로 고르고, 회차에 없는 기능("!")은 권하지 않기
3. **어두운 날에는 LED·화면 불빛을 더 밝게**: 기획의 "어두우면 LED가 눈에 띈다"를 살려서, 어두운 회차는 오히려 전자기기 학생 찾기가 재밌게
4. **물병·휴대폰도 "눈에 띈 것" 한 줄**: "물병을 마시지 않고 라벨만 오래 본다", "책상 밑에서 화면 불빛"
