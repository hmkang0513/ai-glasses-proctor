- 대상: `localhost:5181` 미리보기(커밋 527fc86 "플레이테스트 5차 반영", e256815 "학생 몸을 칠판 방향으로 고정")
- 방식: PC 1440×810(키보드), 휴대폰 844×390(터치). 길 찾기 때만 현재 위치를 읽음. 누가 부정행위자인지는 결과 전까지 읽지 않음
- 스크린샷: `docs/playtest-r6/` (방향 `o*`·`w*`, 8회차 `r8_*`, 9회차 `r9_*`, 11회차 `r11_*`, 휴대폰 `mb1_*`·`mb2_*`)
- 난이도 상향 제안 없음

## ① 학생 방향 (칠판 방향 고정)

**결론: 자연스러움. 크게 튀는 각도는 못 찾음.**

| 보는 위치 | 결과 | 스크린샷 |
|---|---|---|
| 교탁 앞(정면) | 앞얼굴, 고개 숙여 책상 보기. 자연스러움 | `o1_front` |
| 교탁 앞에서 좌우로 고개 | 대각 학생은 살짝 옆을 향한 얼굴. 좋음 | `o2_diagR`, `o3_diagL` |
| 오른쪽 벽 통로(옆) | 옆얼굴·옆몸. 손 든 학생도 옆에서 팔이 보임 | `o4_side`, `o5_side_back`, `o6_side_front` |
| 가운데 통로를 걸으며 | 거리·각도에 따라 앞얼굴 → 반측면 → 옆얼굴로 부드럽게 바뀜 | `w1`~`w12` |
| 교실 뒤(뒷모습) | 뒷머리·등. 1세대 AI 안경 LED가 뒤에서도 빨갛게 보임 | `o7_back`, `o8_backdiag` |
| 아주 가까이·비스듬히 | 바로 옆 학생은 화면을 크게 덮지만 납작해 보이진 않음 | `o9_close`, `o10_close2` |

작은 것:
- **바로 옆(1m 안)에 붙어 정면을 보면 학생 등이 화면 아래쪽을 크게 덮음** (`o10_close2`). 그림 문제라기보다 거리 문제라 그대로 둬도 될 듯
- 옆에서 볼 때 **책상 위 시험지가 납작하게 거의 선**이 됨 (`o4_side`). 자연스러운 원근이지만, 옆에서 "시험지에 무엇을 하는지"는 안 보임. 단서는 관찰창이 보완하니 문제 없음
- 관찰창 얼굴은 여전히 **정면 고정**(뒤에서 보면 "어깨 너머 관찰"로 뒷머리). 일관됨 ✅

## ② 8·9·11회차

| 회차 | 결과 | 흐름 |
|---|---|---|
| 8 | 진행 중 확인만 | 힌트 65초 → 6번. 처음엔 6번 쪽을 보는데 **가까운 18번이 조준선에 걸려** 라벨 "18번 [F] 적발"인 채 F → 18번 오인(내 실수, 라벨은 정확) (`r8_k1`~`r8_k3`). 다시 6번에게 3.6m까지 가서 관찰 → F → **"6번 쪽으로 다가갑니다" → "6번 옆에 왔습니다. 확인하고 F를 한 번 더" → F → 적발** (`r8_m1`~`r8_m4`). "꺼져 있던 시계 화면이 켜졌다!" 문구가 확신을 줌 |
| 9 | 진행 중 확인만 | 작은 목표 "Z로 의심 표시 해 보기" → Z 누르자 바로 달성. 힌트 59초 → 6번 → 두 단계 적발했는데 **무고**(9회차 힌트는 약 70%). 뒤에서 앞줄 가운데 **빨간 LED 빛**이 보였는데 다가가니 뒷모습만 보여 누군지 못 짚음 (`r9`, `r9_d1`) |
| 11 | C | 작은 목표 "Tab으로 CCTV 한 번 보기" 달성. 첫 힌트 **115초** → 2번(물병). 내 쪽 지연으로 시간 초과. 결과: 놓침 2번(물병)·20번 (`r11_z_result`) |

### 발견한 것 (우선순위)
1. **[중간] 뒤에서 LED는 보이는데 다가가면 어느 학생인지 모르겠음** (9회차): 교실 뒤에서는 빛 덩어리가 보이지만, 가까이 가서 뒷모습이 되면 LED가 안 보이거나 앞뒤 학생과 겹침. 뒤에서 LED가 보일 때 **그 학생의 의자·책상에도 빛이 살짝 비치면** 위치를 잡기 쉬울 듯
2. **[중간] 가까운 학생이 조준선에 걸리면 먼 목표를 고르기 어려움** (8회차): 라벨은 정확해서 버그는 아님. 다만 F가 "가까우면 즉시 적발"이라 실수 비용이 큼. 가까운 학생도 **F를 처음 누르면 확인 한 번**(관찰창 강조 + "F 한 번 더")으로 통일하면 오인이 줄 것 같음
3. **[낮음] 9회차 힌트가 같은 틀린 자리(6번)를 3초 뒤 또 반복** — 반복 자체는 괜찮지만, 틀린 힌트일 때 반복되면 더 믿게 됨
4. **[낮음] 11회차 결과 한마디 "막히면 H를 눌러 부감독에게 물어보세요"** — 좋음. "무고한 학생을 잘못 잡지 않았어요"와 함께 나와 상황에 맞음 ✅
5. **[낮음] 9회차 이상은 어두운 날이 다시 나옴**(6~8은 없음) — 의도된 계단이면 OK. 9회차 뒤쪽은 학생 구분이 꽤 어려움 (`r9`)

## ③ 휴대폰 1~2회차 자동 다가가기

**결론: 두 단계(관찰창 → 다가가기 → 확인 후 적발) 흐름이 자연스럽게 동작함 ✅**

- 2회차 17번 (`mb2_2`~`mb2_6`): 3.6m에서 적발 탭 → "먼저 관찰창을 열었어요. 확인한 뒤 적발을 한 번 더 누르세요"(흐릿함 안내 함께) → 다시 탭 → "17번 쪽으로 다가갑니다" + "17번 적발 버튼: 옆으로 다가가기" → 도착하면 관찰창이 **선명하게** 다시 열리고 "주먹 쥔 손가락 사이로 파란 잉크가 비친다" → 탭 → 적발. 오타 수정도 확인 ✅
- 1회차 5번: 가까이(2.4m)에서 가운데 조준 → 탭 → 관찰창 → 탭 → 적발, S (`mb1_12`~`mb1_15`)

### 휴대폰에서 발견한 것
1. **[높음] 조준이 안 된 상태에서 적발을 누르면 PC 문구 "적발할 학생을 먼저 관찰(E)하세요"가 뜨고, 연타하면 두 줄로 겹침** (`mb1_2`, `mb1_9`). 휴대폰에서는 "학생을 화면 가운데에 두고 적발 버튼"처럼
2. **[중간] 바로 옆(2.4m)에 또렷이 보이는 학생도 화면 가운데가 아니면 조준이 안 됨** (`mb1_7`: 5번이 오른쪽에 LED까지 켜고 크게 보이는데 target 없음). 터치는 미세 조준이 어려우니 휴대폰은 조준 폭을 넓히거나, **가운데에 아무도 없을 때 가장 가까운 화면 안 학생을 고르기** 제안
3. **[중간] 먼 학생(7m)은 아예 조준이 안 돼서 자동 다가가기를 쓸 수 없음** (`mb1_1`: 5번 약 7m, target 없음). 관찰 거리(4.2m) 밖이라 그런 듯. "멀리서 F로 다가가기"가 휴대폰에서 가장 쓸모 있는 건 먼 거리라 아쉬움
4. **[낮음] 왼쪽 드래그 걷기가 책상에 자주 막힘**: 앞으로 끌면 바로 앞 책상에 걸려 안 움직이고, 옆으로 비켜야 통로로 감. 키보드보다 막힘을 알아채기 어려움(멈춰 있는 이유가 안 보임)
5. **[낮음] 입실 검사 시계가 08:00에 멈춰 보임**: 20번째 학생, 내부 시간 76초인데 화면은 "08:00 입실 마감 08:10 20/20" (`mb2_0`). PC에서도 같은지 확인 필요

## 좋아진 것 ✅
- 자동 다가가기 두 단계: 오인 걱정 없이 멀리서 누를 수 있음(PC·휴대폰 모두)
- 오늘의 작은 목표(Z 표시, CCTV 보기): 새 기능을 자연스럽게 한 번씩 써 보게 함. 달성 토스트·결과 별 표시 OK
- Z 의심 표시 안내 "머리 위 메모일 뿐, 판정과는 상관없어요" — 헷갈림을 미리 막아 줌
- 관찰창 "눈에 띈 것": "꺼져 있던 시계 화면이 켜졌다!", "주먹 쥔 손가락 사이로 파란 잉크가 비친다" — 확신을 줌
- 결과 한마디가 상황에 맞음(11회차)

## 아이디어
1. **휴대폰 "가장 가까운 학생 자동 조준"**: 화면 가운데가 비어 있으면 화면 안에서 가장 가까운 학생에게 조준 틀을 붙임
2. **뒤에서 보이는 빛을 그 학생 자리에 묶기**: LED 빛이 책상·의자에 반사되는 작은 원을 그려 위치를 쉽게
3. **걷다가 막히면 짧은 표시**: 책상에 막혔을 때 화면 아래에 "책상에 막혔어요 · 옆 통로로" 한 번
