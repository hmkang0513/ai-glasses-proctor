### 증거물 카드 — 분위기는 좋다, 사진과 뒷면을 다듬자 [확인]
- 결과 화면 위에 살짝 기울어진 폴라로이드가 뜨고, "증거물 · AI 안경 (1세대) / 한빛고 5번 · 1번째 감독"이 손글씨처럼 보인다. 누르면 뒷면, 다시 누르면 닫힌다. 흐름 좋다.
1. **사진 속 학생 눈이 감겨 있다.** 1회차 카드 사진이 눈 깜빡임 프레임(가로선 눈)으로 찍혀 졸거나 물 마시는 얼굴처럼 보인다. 카드용으로 그릴 때는 **깜빡임을 끄고 눈을 뜬 상태로 고정**한다. 1세대면 LED도 켠 상태로 고정한다.
2. **뒷면 아래 절반이 비어 있다.** 수법 이름, "실제 사례 · 토익 2026 AI 글라스 적발", 설명 두 줄 뒤로 카드의 40%가 빈칸이다. 아래쪽에 두 가지를 넣으면 꽉 찬다.
   - 출처 주소 앞 40자(8px, `#7d776b`)
   - "{월}.{일} · 제{n}시험실" 날짜 도장(빨간 원 테두리 28×28, 3° 기울임)
3. 앞면 아래 "처음 밝혀낸 수법 · 누르면 뒷면" 안내가 결과 화면 버튼("다음 감독") 위에 겹쳐 보인다. 안내를 카드 바로 아래(`y 214`)로 올리면 겹치지 않는다.

## ③ 휴대폰에서 더 편해질 점 3개 [확인]

### 1. 터치로 해도 첫 메모가 "WASD로 걷고 마우스로…"라고 나온다 (문구 버그)
- 세로·가로 휴대폰 캡처 모두 1회차 메모 첫 줄이 **"WASD로 걷고 마우스로 고개를 돌립니다. (화면을 클릭하면 마우스가 고정됩니다)"**였다.
- 원인 [코드 분석]: 터치일 때 바꿔 끼우는 문장(`exam.ts` 1267줄 `.replace("WASD로 걷고, 마우스로 고개를 돌립니다. 화면을 클릭하면 마우스가 고정됩니다.", …)`)이 `levels.ts` 39줄의 지금 문장("WASD로 걷고 마우스로 고개를 돌립니다. (화면을 클릭하면 마우스가 고정됩니다)")과 쉼표·괄호가 달라서 **바뀌지 않는다.**
- 고치는 법: 문장 통째 바꾸기 대신 **id로 고르게** 한다(메모 줄에 `{pc: "...", touch: "..."}` 두 벌). 지금 당장은 replace 대상 문장을 39줄과 똑같이 맞추면 된다. 터치 문장: "화면 왼쪽을 끌면 걷고, 오른쪽을 끌면 고개를 돌립니다."

### 2. 화면 속 학생을 톡 누르면 바로 그 학생을 관찰
- 지금은 오른쪽을 끌어 학생을 화면 가운데에 맞춘 뒤 "관찰" 버튼을 눌러야 한다. 작은 화면에서 조준이 가장 번거롭다.
- 제안: 화면에 보이는 학생 스프라이트를 **탭하면** 감독관이 그 학생 쪽으로 0.3초 동안 고개를 돌리고 바로 관찰창을 연다(4m 밖이면 지금의 자동 다가가기를 쓴다). 적발은 지금처럼 "적발" 버튼을 두 번 누른다(실수 방지 유지).
- 판정용 사각형은 그려진 스프라이트 크기 그대로 쓰되, 최소 44×44 CSS px로 키운다.

### 3. 입실 검사의 작은 물건을 누르기 어렵다 + 버튼에 키보드 숫자가 보인다
- 가로 휴대폰에서 입실 화면 바구니의 **펜은 내부 30×4px**이라 실제 화면에서 높이가 7px 남짓이다. 손가락으로 고르기 어렵다. 동전(9×9), 지우개(16×9)도 작다.
  - 터치일 때는 물건마다 **보이지 않는 터치 상자를 최소 32×24(내부 px)**로 키운다.
  - 또는 바구니 아래에 물건 이름 버튼 줄(안경·시계·필통·지우개·펜…)을 띄워 이름으로 고르게 한다.
- 버튼 글자 "1 · PASS 통과", "2 · HOLD…", "3 · CHECK…"의 숫자는 키보드용이라, 터치에서는 **"통과", "보관", "몸 수색 (6초)"**만 크게 쓴다.
- 함께: 가로 화면에서 게임 화면 왼쪽에 검은 여백(약 180 CSS px)이 남는다. 이동 조이스틱 자리를 그 여백 가운데에 **옅은 원(지름 120 CSS px)**으로 늘 그려 두면 "왼쪽을 끌면 걷기"가 눈으로 보인다.
