# 플레이테스트 1라운드 (2026-11-18)

- 방식: Playwright(msedge, 1440×810)로 띄운 브라우저에 **키보드(WASD·방향키·E/F/T/R/Tab/Q·숫자)와 마우스 클릭만** 보냄. `window.__game`으로 순간이동하거나 시간을 조작하지 않음. 판단은 스크린샷으로 함
- 예외: 좁은 통로에서 길을 잃었을 때 **현재 위치만 읽어** 몸을 돌릴 각도를 계산함(사람의 공간 감각 대신). 학생 정보(누가 부정행위자인지)는 결과 화면이 나오기 전까지 읽지 않음
- 한계: 명령 한 번에 10~30초가 걸려서 **실시간 압박(입실 검사 100초, 시계 확인 12초)은 사람보다 훨씬 불리**했음. 입실 검사는 20명을 빠르게 넘기며 화면을 기록하고, 단서는 나중에 모아 보며 판단함. 50회차는 시간 부족으로 하지 못함
- 스크린샷: `docs/playtest-r1/` (아래 파일 이름은 이 폴더 기준)

## 요약: 가장 큰 문제 3개

1. **CCTV 모드로 저장된 채 다음 판을 시작하면 시계 확인(12초)을 통째로 버림**: 시작 모드가 저장된 CCTV로 열리는데, 시계 확인 중에는 Tab이 막혀(M3 수정) 1인칭으로 돌아갈 수 없음. 12회차에서 WASD가 먹지 않은 채 12초가 지나감 (`lv12_10_pre11.png`~`lv12_12_pre11F.png`)
2. **안내 문구가 다른 문구와 겹쳐서 읽을 수 없음**:
   - 시계 확인 안내("학생들이 시계를 책상 위에 올려 둡니다 · 스마트워치는 관찰(E) 후 F로 보관")가 "화면 클릭 → 마우스 고정 · Q 명부 보기"와 같은 높이에 겹침 (`lv4_10_pre.png`)
   - 1회차 수석감독관 메모의 마지막 줄이 "클릭하거나 Space를 누르면…"과 겹침 (`lv1_01_start.png`)
   - 결과 화면의 놓친 학생 설명이 "…감독관이 가까이서 본 건"에서 잘림 (`lv25_40_result.png`)
3. **조준 표시와 조준 대상 때문에 수상한 학생을 보기 어려움**:
   - "4번 [E] 관찰" 라벨이 바로 오른쪽 학생(LED가 켜진 부정행위자 5번)의 얼굴을 덮음 (`lv1_04_right.png`, `lv1_08_turn.png`)
   - 가까운 학생이 화면을 넓게 차지하면 그 뒤 학생은 조준할 수 없음. 창가의 팔 든 학생을 보려 했지만 계속 바로 앞 13번이 잡힘 (`lv4_28.png`~`lv4_30_obs.png`)

## 회차별 기록

### 1회차 — 가람고 제24시험실 · 결과 S (40초 만에 종료)
1. **할 일을 알았는지**: 메모(`lv1_01_start.png`)를 보고 바로 알았음. "두세 걸음 떨어져서 지켜보세요"는 좋은 안내. 다만 마지막 줄이 하단 문구와 겹치고, 본문이 모두 빨간색이라 강조가 없음
2. **화면으로 찾을 수 있었는지**: 쉬웠음. 교실 앞에서 고개만 돌려도 오른쪽 끝 5번의 **빨간 LED 불빛이 멀리서도 보임** (`lv1_07_observe.png`). 관찰 패널에서 두꺼운 테 + 경첩 카메라가 또렷함 (`lv1_10_closeup.png`). 1회차로는 적당히 뻔함
3. **버그·불편**:
   - 조준 라벨이 옆 학생 얼굴을 덮음(위 3번)
   - 관찰 뒤 "가까이 가면 [F] 적발"이 떠도 앞으로 0.8m쯤 더 걸어야 했음. 걷는 속도가 느리게 느껴짐(1.7m/s)
4. **재미/지루함**: 멀리서 빨간 불빛을 발견하는 순간이 좋았음. 너무 빨리 끝나서 다른 조작(T·Tab)은 써 볼 일이 없었음

### 4회차 — 해오름고 제10시험실 · 결과 D (놓침 6·10번 옆자리 훔쳐보기, 민원 1)
1. **할 일을 알았는지**:
   - 입실 검사에 도움말이 없음(1~3회차만). 그래도 버튼 이름으로 짐작은 됨
   - 시계 확인은 처음 보는 단계인데 안내 문구가 겹쳐서 못 읽음(위 2번)
2. **화면으로 찾을 수 있었는지**:
   - 입실 검사 20명(`lv4_g01.png`~`lv4_g20.png`)에서 **아무 단서도 없었음**. 이번 수법(옆자리 훔쳐보기)은 입실 검사와 관계가 없으니 맞지만, 플레이어 입장에서는 20명 PASS만 누르는 지루한 구간
   - 금속 탐지 막대가 **아무 금속이 없는 부위(발·몸통)에도 한 칸씩 깜빡임**. 단서처럼 보여서 헷갈림 (예: 9번 머리·발, 12번 손목)
   - 시험 중에는 못 찾음. 부감독 헛기침 힌트("10번 쪽")를 따라가 10번을 10초 가까이 지켜봤지만 계속 필기만 함 (`lv4_36_10.png`~`lv4_41.png`). 결과를 보니 10번이 정답이었음. 가까이(약 2.2m) 있으면 멈추는 규칙 때문에 사람이 지켜볼 수 있는 거리에서는 행동이 안 나옴. "얼마나 떨어져야 하는지" 감이 안 옴
   - CCTV(`lv4_60_cctv.png`~`lv4_63_cctv.png`)는 노이즈와 작은 크기 때문에 **누가 무엇을 하는지 전혀 구분이 안 됨**. 팔을 든 모양 정도만 보임
3. **버그·불편**:
   - 쳐다봄 민원이 **모르는 사이에 두 번** 들어옴. 시계 확인 때 3번 옆에서 관찰하던 중, 그리고 통로에서 길을 찾다가 15번 앞에 멈췄을 때. 토스트를 못 봐서 왜 민원이 생겼는지 몰랐음 (`lv4_35.png`에서 민원 1칸)
   - 시계 확인은 가까이 가서 관찰해야 하는 단계인데, 가까이 오래 있으면 민원이 쌓임. 두 규칙이 부딪힘
   - 좁은 통로에서 학생 바로 뒤에 붙으면 화면 가운데가 머리로 꽉 참 (`lv4_31_to10.png`)
4. **재미/지루함**:
   - 재미: 부감독 헛기침 힌트가 뜬 순간 "가 봐야지"라는 목표가 생김
   - 지루함: 아무것도 없는 입실 검사 20명, 2교시 3분을 CCTV로 봐도 판단할 거리가 없음

### 12회차 — 다온고 제27시험실 · 결과 C (적발 19번 AI 안경 2세대, 오인 11번, 놓침 2번 지우개·6번 손바닥, 민원 1.5)
1. **할 일을 알았는지**: 알았음. 단, 시작하자마자 CCTV 화면이라 당황함(위 1번)
2. **화면으로 찾을 수 있었는지**:
   - **입실 검사 단서가 좋았음**: 19번 안경 경첩에 검은 카메라 구멍 + 머리 금속 4칸(주황 포함) (`lv12_g19.png`). 다만 빠르게 넘기다 놓쳤고, 시험 중에 다시 찾음
   - **시험 중 19번**: 시험지를 얼굴까지 들어 올림 → 관찰 → 열화상에서 경첩이 뜨거움 → 동시에 부감독 힌트도 19번 (`lv12_22.png`, `lv12_25_thermal19.png`). **단서 세 개가 맞아떨어지는 최고의 순간**
   - **11번 오인**: 입실 때 확대경에 검은 사각 시계가 보여서 스마트워치라고 생각함 (`lv12_g11.png`). 관찰 패널에서도 검은 시계 (`lv12_28_obs11.png`). 그러나 무고한 학생. **검은 아날로그 시계와 스마트워치를 구분할 단서**(화면 빛·숫자 표시 등)가 확대경에서도 약함
   - 2번 지우개 쪽지는 입실 검사에서 지우개를 **직접 클릭해야** 보이는데, 기본 선택이 안경·필통이라 20명을 빨리 넘기면 볼 일이 없음
3. **버그·불편**:
   - CCTV 시작 + 시계 확인 낭비(위 1번)
   - 쉬는 시간 화면이 20초 뒤 자동으로 넘어가 2교시가 시작됨(클릭 안 해도). 의도라면 괜찮지만, 화면 밖을 보다 오면 2교시가 이미 진행 중
4. **재미/지루함**: 19번 장면이 가장 재미있었음. 입실 검사에서 본 단서가 시험 중 행동으로 이어지는 흐름이 좋음

### 25회차 — 도담고 제6시험실 · 결과 D (적발 7번 하이브리드 워치, 놓침 1번 AI 안경 일반형·11·13·17번)
1. **할 일을 알았는지**: 대체로 앎. 새 도구 **"R 전파"**가 관찰 패널 제목에 처음 나왔는데 설명을 본 적이 없음 (`lv25_10_pre7.png`)
2. **화면으로 찾을 수 있었는지**:
   - 입실 검사에서 7번 시계 확대경에 **작은 파란 화면**이 보여 하이브리드 워치임을 알 수 있었음. 좋은 단서 (`lv25_g07.png`)
   - 17번은 뿔테(금속 아님)인데 머리 금속이 4칸이라 의심함 (`lv25_g17.png`). 시험 중 관찰·열화상·전파를 써 봤지만 판단이 안 됨. 전파 바늘이 가운데쯤인데 **기준선이 없어서 높은지 낮은지 모르겠음** (`lv25_21_R17.png`). 결과를 보니 17번은 부정행위자였음
   - 놓친 1번(AI 안경 일반형)은 "38번 행동"했다고 나옴. 앞줄 창가 끝이라 한 번도 보러 가지 않았음. 교실 반대편을 안 보면 몇 번이든 행동해도 모르는 구조
3. **버그·불편**:
   - 결과 화면 설명 잘림(위 2번). 놓친 학생이 4명인데 공개 상자는 1개만 나옴
   - 자리 배치도에 파란 점과 초록 네모(감독관 동선·머문 시간으로 보임)가 표시되는데 설명이 없음. 점이 배치도 밖(FRONT 띠 위)까지 찍힘
   - "카드 저장" 버튼이 새로 보이지만 테스트하지 않음
4. **재미/지루함**: 입실 단서로 7번을 시험 시작 직후 잡은 것은 좋았음. 17번처럼 단서가 애매한 학생 앞에서 도구를 다 써도 결론이 안 나는 시간이 답답함

## 개선 아이디어
- **시험 시작은 항상 1인칭**으로 하거나, 시계 확인 중 CCTV이면 1인칭으로 자동 전환
- 조준 라벨을 대상 **위쪽**(머리 위)으로 올리고, 옆 학생과 겹치면 반대쪽으로 붙이기
- 조준 대상 우선순위: 가운데에 가장 가까운(각도 기준) 학생을 고르고, 가려진 뒤쪽 학생도 Q/E 길게 누르기 등으로 고를 수 있게
- 쳐다봄 민원 직전에 **경고**(학생이 감독관을 힐끗 봄 + "불편해 보입니다") 한 번 주기. 시계 확인 시간에는 쳐다봄 민원 끄기
- 금속 탐지 깜빡임 노이즈는 **값이 있는 부위만** 흔들리게
- 전파 계기판에 "평소 수준" 기준선 표시, 첫 등장 때 한 줄 설명
- 입실 검사: 의심 학생이 없는 회차에는 인원을 줄이거나, 단서가 있는 물건을 기본 선택으로(또는 "다음 물건" 키를 안내)
- 결과 화면: 놓친 학생이 여럿이면 "외 n명 · 클릭해서 더 보기"
