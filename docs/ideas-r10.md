## ① 9라운드 반영분 점검

### 자동 다가가기 — 통로에서는 잘 되고, 같은 열 앞뒤에서는 책상에 막힌다 [확인]

| 출발 위치 (8번 기준) | 처음 거리 | 결과 |
|---|---|---|
| 앞쪽 대각선 통로 | 3.15m | 0.5초 만에 2.4m 도착 → 적발 판정 |
| 두 열 옆 통로 | 3.05m | 0.4초 만에 도착 → 적발 판정 |
| 뒤쪽 대각선 통로 | 3.15m | 0.5초 만에 도착 → 적발 판정 |
| **정면 앞 빈칸(같은 열)** | 3.3m | **2.65m에서 멈춤**, 4초 뒤 아무 안내 없이 취소 |
| **뒤쪽 같은 열** | 3.3m | **2.76m에서 멈춤**, 4초 뒤 아무 안내 없이 취소 |

- 원인: 목표 지점(학생 앞 0.9m)으로 **직선**으로 걷는데, 같은 열에서는 사이에 있는 책상에 정면으로 막힌다 [코드 분석]. 막히면 4초 동안 제자리에서 걷는 모션만 하다가 조용히 취소된다. 플레이어는 "F가 안 먹힌다"고 느낀다.
- 제안(작은 것부터):
  1. **막혔을 때 3.0m 안이면 그 자리에서 바로 적발 처리**한다. 가장 간단하고, 거리 0.4~0.6m 차이라 어색하지 않다.
  2. 목표 지점을 "학생 앞"이 아니라 **가장 가까운 통로의 학생 옆 지점**(학생 x ± 0.95, 같은 z)으로 바꾼다. 통로는 비어 있으니 같은 열에서도 옆으로 비켜서 들어간다.
  3. 그래도 취소되면 "책상에 막혔습니다 · 통로로 돌아가세요" 한 줄을 띄운다(조용한 취소 없애기).

### NEW 딱지 — 빈도는 적당하다 [코드 분석]
- NEW는 "수첩에 없는 수법의 단서를 이번 판에 처음 본 순간" 한 번만 뜬다. 1~20회차에 처음 나오는 수법이 16개 정도(AI 1세대, 손바닥, 지우개, 옆자리, 휴대폰, 종료령 뒤 작성, 스마트워치, 물병, AI 2세대, 팔 메모, 자, 창밖 쪽지, 이어폰, 기침 신호, 바꿔치기, 화장실 반입)라서 **대략 1~2회차에 한 번**꼴이다. "가끔 새로운 게 나온다"는 느낌으로 딱 좋다.
- **[하]** 입실 검사에서 보관(HOLD)한 수법은 결과 화면에서 수첩에 적히므로, 시험 중에는 NEW가 뜨지 않는다. 처음 만난 장소가 입실이면 **입실 화면 확대경에도 같은 NEW 딱지**를 띄우면 일관된다.
- **[하]** 1회차는 관찰 패널을 처음 여는 순간 "안경다리가 유난히 두껍다 + NEW"가 바로 뜬다. 튜토리얼과 겹쳐 정보가 많을 수 있으니, 1회차만 NEW를 1초 늦게 띄우는 걸 권장한다.

## ② B · C · D 중 먼저 넣을 것 — **B → C → D 순서 권장**

| 순위 | 항목 | 이유 |
|---|---|---|
| 1 | **B. 명부 학생 한 줄 소개** | 가장 작고, 모든 회차에서 "미끼 때문에 헷갈림"을 바로 줄인다. 기존 습관 프로필을 그대로 쓴다 |
| 2 | **C. 10회차 열화상 시범** | 10회차 한 번만 쓰이지만 "열화상은 만진 직후"라는 가장 헷갈리는 규칙을 손으로 익힌다 |
| 3 | **D. 교실 분위기** | 분위기 다양화. B가 있으면 그날의 습관이 명부에도 보여서 효과가 커진다 |

### B. 명부 학생 한 줄 소개 — 규칙과 문구표
**규칙**
- Q 명부에 "학생 메모" 쪽을 하나 추가한다. 20줄로 `NN번 · 한 줄`을 적는다.
- 관찰 패널을 열면 머리줄 "5번 관찰 중" 옆에도 같은 한 줄을 작게 붙인다.
- **모든 학생에게 한 줄이 있다.** 비어 있으면 그 자체가 신호처럼 보이므로 피한다.
  - 무고한 학생: 미끼 습관(`habits`의 마지막 값). 없으면 기본 습관 문구.
  - 부정행위자: 기본 습관(`think`·`stretch`·`drink` 중 하나) 문구 또는 아래 "평범한 한 줄" 중 하나.
  - 재수생: 앞에 "재응시 · "를 붙인다(이미 있는 명부 메모와 통일).
  - 소심한 학생(`timid`): "수줍음이 많음"을 우선한다.

**문구표 (습관 → 한 줄)**

| 습관 | 한 줄 |
|---|---|
| `think` | 어려운 문제에서 턱을 괴는 편 |
| `stretch` | 오래 앉아 있으면 기지개를 켬 |
| `drink` | 물을 자주 마심 |
| `cough` | 감기 기운이 있음 |
| `lookaround` | 목이 뻐근하다고 함 |
| `ear` | 귀를 자주 만지는 버릇 |
| `clothes` | 교복이 커서 자꾸 고쳐 입음 |
| `neck` | 목을 자주 돌림 |
| `nosepush` | 안경이 자꾸 흘러내림 |
| `glassesoff` | 렌즈를 자주 닦음 |
| `temple` | 안경을 자주 고쳐 씀 |
| `wrist` | 시계를 자주 봄 |
| `underdesk` | 다리가 자주 저림 |
| `palm` | 손이 차가워 자주 비빔 |
| `glance` | 주변을 잘 살피는 편 |
| `timid` (성격) | 수줍음이 많음 |
| `hum` (다리 떨기) | 긴장하면 다리를 떪 |
| `window` | 창가 자리를 좋아함 |

**평범한 한 줄 (부정행위자·습관 없는 학생용, 무작위)**: "조용한 편", "필기가 빠름", "아침을 거르고 옴", "도시락을 챙겨 옴", "일찍 입실함", "수험표를 두 번 확인함"

### C. 10회차 열화상 시범 — 순서표
| 단계 | 시점 | 무엇이 일어나나 | 문구 |
|---|---|---|---|
| 1 | 10회차 시계 확인 시작 | 부감독이 교탁 옆으로 와서 선다(뒷문 자리 대신) | 토스트: "부감독: 새 장비 한번 써 보세요. 제 안경으로 보여 드릴게요" |
| 2 | 플레이어가 부감독을 조준 | 부감독이 자기 안경다리를 손가락으로 누르는 동작(1초) | 라벨: "부감독 [T] 열화상" |
| 3 | T 누름 | 관찰 패널 모양으로 부감독 얼굴 열화상, 안경다리가 빨갛게 | 패널 위: "안경다리가 뜨겁다! 이렇게 보여요" |
| 4 | 약 4초 뒤 다시 T | 안경다리가 식어 파란색 | 패널 위: "만진 직후 10초만 뜨거워요. 식으면 안 보여요" |
| 5 | 끝 | 부감독이 뒷문 자리로 돌아감. 열화상 횟수는 줄지 않음(시범용) | 토스트: "부감독: 이제 실전입니다. 안경다리를 만진 학생이 보이면 바로 T!" |

- 플레이어가 아무것도 안 하고 시계 확인 12초가 끝나면 시범은 건너뛰고, 10회차 메모(이미 있음)로 대신한다.
- 16회차 전파 탐지기도 같은 순서로 한다(부감독의 무전기를 보여 주며 R).

### D. 교실 분위기 — 테마표
- 6회차부터 판마다 30% 확률로 테마 하나. 명부 첫 줄에 "오늘은 ○○입니다" 한 줄을 넣는다.
- **무고한 학생의 습관 가중치와 연출만 바꾸고, 부정행위자 수·단서는 그대로 둔다.**

| 테마 | 명부 문구 | 바뀌는 것 |
|---|---|---|
| 더운 날 | 오늘은 더운 날입니다. 물 마시는 학생이 많아요 | 무고한 학생 `drink` 가중치 ×3, 창문 열림(조명 밝게), 매미 소리 대신 선풍기 소리 |
| 감기 유행 | 감기가 유행입니다. 기침 소리가 잦아요 | `cough` ×3, 자막 "기침"이 자주 뜸, 일부 학생 마스크(얼굴 아래쪽 흰 픽셀) |
| 비 오는 날 | 비가 옵니다. 교실이 조금 어둡습니다 | 조명 `overcast`, 빗소리 배경, 창밖 쪽지 이벤트는 그날 없음 |
| 월요일 아침 | 다들 피곤해 보입니다 | `stretch` ×2, 하품 동작(머리 위로 손) 추가 |
| 시험 직전 긴장 | 다들 긴장했어요 | 소심한 학생 +1, 다리 떨기 소리(`hum`) ×2 |

## ③ 11~20회차를 쉬운 난이도 그대로 즐겁게 — 아이디어 3개

### 1. 반장의 제보
- **무엇**: 11회차부터 판마다 한 번, 앞줄의 "반장" 학생(명부에 "반장"으로 표시)이 시험 중 조용히 손을 든다. 다가가 E를 누르면 작은 목소리로 **들은 것**을 알려 준다. 예: "뒤쪽에서 지잉 소리가 났어요", "창가 쪽 친구가 자꾸 창밖을 봐요". 구역만 알려 주고 좌석은 말하지 않는다.
- **왜 재밌나**: 학생이 감독관 편이 되는 따뜻한 순간이다. 힌트를 받으러 가는 작은 이동이 생기고, 11~20회차에 새로 나오는 소리 단서(진동, 속삭임)를 자연스럽게 소개한다.
- **현실 근거**: **[게임 설정]**
- **구현 크기**: 소~중 (H 힌트 로직 재사용)

### 2. 하루 끝 교무실 한 컷
- **무엇**: 결과 화면 다음에 2~3초짜리 짧은 컷을 넣는다. 교무실 책상에 커피와 감독 명부가 있고, 동료 감독관이 한마디를 던진다. 예:
  - "오늘 우리 반에선 시계 화면이 켜지는 애가 있었대요"
  - "요즘 AI 안경 뉴스 보셨어요?"

- **현실 근거**: 실제 사례 한 줄은 `cheats.ts` 출처를 쓴다. 대화는 **[게임 설정]**.

### 3. 오늘의 작은 목표 (선택)
