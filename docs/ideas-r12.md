## ④ 반장의 제보 — 세부 규칙표

**원칙**: 제보는 **항상 맞는 정보**다(쉬운 난이도). 좌석이 아니라 **구역과 들은 것**만 말한다. 무시해도 아무 불이익이 없다. **한 손만 드는 동작**이고 만세가 아니다.

| 항목 | 규칙 |
|---|---|
| 누가 | 앞줄(1~5번) 중 **부정행위자가 아니고 소심하지 않은** 학생 1명을 판 시작 때 고정. 명부 한 줄 소개를 "반장 · 늘 차분함"으로 바꾼다. 앞줄이 모두 해당 없으면 둘째 줄에서 고른다 |
| 언제부터 | 11회차부터 |
| 몇 번 | 교시당 1번 |
| 언제 | 교시 시작 후 40~90초 사이 무작위. 단 아래일 때는 미룬다: 정전 중, 듣기평가 중, 답안지 회수 중, 시계 확인·장비 시범 중, 남은 부정행위자 0명(이때는 그 교시 제보 없음) |
| 어떻게 알리나 | 반장이 **한 손**을 든다(`handup`의 한쪽 팔만). 머리 위에 작은 손 모양 아이콘(8×8, `#f4f2ea` 바탕 + `#e0b48e` 손) 표시. 자막·토스트 "▲ 반장이 손을 들었습니다"(방향 화살표는 소리 자막과 같은 규칙) |
| 플레이어 행동 | 반장에게 2.6m 안으로 가서 E(관찰)를 누르면 제보를 듣는다. 관찰 패널 대신 **말풍선**(관찰 패널 자리, 200×40)에 문구가 뜬다. F는 반장에게 쓰지 않는다(눌러도 "반장은 제보하러 손을 든 겁니다" 안내만) |
| 기다림 | 30초 안에 오지 않으면 손을 내린다. 불이익 없음. 같은 교시에 다시 들지 않는다 |
| 무엇을 말하나 | 남은 부정행위자 중 **반장에게서 가장 먼 사람** 한 명을 골라 아래 "구역 × 단서 종류" 조합으로 말한다 |
| 어디에 남나 | ① 제보 문구는 Q 명부 "학생 메모" 쪽 맨 위에 "반장 제보: …"로 남는다. ② 그 구역 바닥에 연한 주황 테두리(구역 사각형, 투명도 0.25)가 10초 동안 보인다. ③ CCTV 화면에도 같은 구역 테두리가 10초 |
| 작은 목표 | 11회차 이후 목표 목록에 `["report", "반장 제보 들어 보기", 11]` 추가 |
| 교무실 대사 | 제보를 들은 판: "반장이 제보해 줬다면서요? 요즘 애들 참 든든하네요." |

| `bottle` (물병 라벨 메모 보기, 부정행위) | 앞모습: 물병을 **가슴 아래**(`Y - 8`)에 둔다 | 물병을 그냥 들고 있는 모습. 라벨을 "보는" 느낌이 약하다 |

**고치는 방법** (사용자 말대로 두 높이를 맞바꾸고, 마시는 동작은 입에 대고 기울인다) — 앞모습 스프라이트 기준 `CX = 16`, 눈 `ey = hy + 5`, 입 ≈ `hy + 8`
