- 휴대폰에서 **적발 버튼을 빠르게 두 번** 누르면 관찰창 → 다가가기가 바로 이어져서, 관찰창을 볼 새 없이 걸어감 (`mz_3`). 도착 후 확인이 한 번 더 있으니 오인은 없음. 다만 첫 탭 직후 0.5초쯤은 두 번째 탭을 무시하면 더 차분할 듯
- 시계 확인 중에도 "책상에 막혔어요"가 뜨는데, 이때는 시계 확인 안내 줄과 위아래로 붙어 화면 위쪽이 복잡함 (`f_1_blocked`)

## ② 13~20회차

해 본 것: 13회차(1교시, 배포 전 빌드), 16회차(1교시). 14·15·17~20회차는 시간 부족으로 못 함.

### 13회차
- 명부: "다들 긴장했어요. 눈이 마주치면 움찔하는 학생이 있습니다" + 작은 목표 "Tab으로 CCTV 화면 한 번 보기" (`q13_memo`). **11회차와 같은 작은 목표**라 연달아 하면 반복으로 느껴질 수 있음
- 72초에 부감독 힌트(11번)와 반장 제보 문구가 같이 뜸. 두 문구가 동시에 나오면 무엇부터 할지 헷갈림

### 16회차 (전파 시범)
- 명부 "시험장 지급 장비: 전파 탐지기(R) … 교시당 2회" → 명부를 닫자 **시범**: "부감독 시범: 무전기를 켜면 바늘이 빨간 '송신' 쪽으로!" → "끄면 바늘이 '평소'로. 학생을 관찰하며 R을 쓰세요" (`q16_b1`~`q16_b4`). 순서가 분명하고 이해 쉬움 ✅
- 시범 중 **전파 계기판 상자가 조준 라벨("3번 [E] 관찰")을 덮음** (`q16_b1`, `q16_b2`)
- 63초 반장 제보(1번), 78초 부감독 힌트(16번) → 16번 관찰 "시험지를 얼굴 가까이 들고 오래 본다" + R 바늘이 송신 쪽 → 두 단계 적발 → "첫 적발! 침착했어요 — 수석감독관" (`q16_c1_R`~`q16_c3`). 단서 두 개가 맞아떨어져 좋았음

### 반장 제보 (11회차~)
- 문구: "1번 반장이 조용히 손을 들었습니다 · 가까이 가서 E" (`q21_t15`). 뒤에서 보면 **반장 머리 위에 작은 네모 표시**가 생겨 위치를 찾을 수 있음 ✅
- **[중간] 늦게 가면 아무 일도 없음**: 21회차에서 약 35초 뒤 도착해 E를 눌렀는데 일반 관찰창("명부: 반장 · 늘 차분함")만 나오고 제보 내용이 없음 (`q21_r2`). 시간이 지나 사라진 건지, 무엇을 놓쳤는지 알 수 없음. 끝났다면 "반장이 손을 내렸습니다" 한 줄, 또는 제보를 교시 끝까지 유지 제안
- **[중간] 반장을 관찰하면 라벨이 "1번 [F] 적발 [E] 닫기"**: 제보를 들으러 간 학생에게 적발 안내가 떠서 실수로 F를 누르기 쉬움. 반장일 때는 "E 제보 듣기"를 먼저

### 교무실 책상
- **미확인**: 이번에는 결과 화면에서 "다음 감독"을 누르지 않고 회차를 직접 열어서 교무실 한 컷을 보지 못함

## ③ 21회차 (학교별 교실 풍경)
- 명부 "비가 옵니다. 교실이 조금 어둡습니다" + 작은 목표 "전파 탐지기(R) 써 보기" (`q21_memo`)
- 교실: 바닥이 밝은 회색빛 나무, 뒤 게시판 색이 달라 **다른 학교에 온 느낌**이 남 (`q21_front`, `q21_left`, `q21_right`, `q21_back`)
- 비: 가까이 가면 **창문에 빗줄기**가 보임 (`q21_r1`). 멀리서는 거의 안 보여 "비 오는 날"을 알아채기 어려움 → 빗소리 자막("♪ 빗소리") 같은 것이 처음에 한 번 뜨면 좋을 듯
- 판은 반장에게 가는 사이 시간이 지나 끝까지 하지 못함

## 고칠 것 (우선순위)
1. [중간] 반장 제보 놓쳤을 때 아무 안내 없음 + 반장 관찰 시 적발 라벨
2. [중간] 16회차 전파 시범 계기판이 조준 라벨을 덮음
3. [낮음] 부감독 힌트와 반장 제보가 같은 순간에 뜸(13회차) → 몇 초 간격
4. [낮음] 작은 목표가 11·13회차에 같음
5. [낮음] 휴대폰 적발 버튼 빠른 연타 시 관찰창을 볼 틈 없음

## 좋았던 점
- 확인 단계 통일로 F가 무섭지 않음. 가까워도 멀어도 같은 흐름
- 휴대폰 자동 조준으로 "왜 안 잡히지?"가 사라짐
- 16회차 전파 시범 → 바로 실전에서 R로 확인하는 흐름
- 학교마다 교실 색이 다르고, 비 오는 날 빗줄기가 있음
